SAHAYAK — Rural Schemes, Savings & Health Guide

Run:
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal in this folder.
4. Run: npm install
5. Run: npm run dev
6. Open the localhost URL shown by Vite in Chrome.

Features:
- Government scheme search and categories
- Health insurance education
- Savings and investment education
- Simple 4-question help finder
- Voice/read-aloud support
- Hindi/English UI control placeholder
- Document checklist
- Responsive mobile-friendly design

This is a frontend prototype. Scheme eligibility, benefits, dates, rates, premiums and application procedures can change; verify current information through official sources before real-world use.
